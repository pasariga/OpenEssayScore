# Contributing

Use an issue or pull request with a reproducible technical case and expected/actual behavior. Install `.[test]`, run `python -m pytest -q`, and run `python tools/backup.py scan .` before sharing. Include dependency versions and aggregate evidence; redact account paths and input records.

Do not submit student essays, real teacher score sheets, API credentials, pretrained weights, private backups or licensed material you cannot redistribute. Technical control strings must be labelled as transport/software fixtures and never reported as human-labelled accuracy evidence. New dependencies need a licence review. Do not use the old exposed test for selection.

Separate changes to source, API contract, model artifacts and rubric. Model proposals require independent data provenance, train/calibration/test isolation, baselines, resource costs, error analysis and stated limitations. Failed experiments are welcome when reported honestly. No automated promotion to stable v2. Contributions to original code use MIT; this does not grant third-party dataset/model rights. CI uses no private model or paid API.
