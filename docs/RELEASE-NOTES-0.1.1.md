# OpenEssayScore 0.1.1 draft / 发行草案

The source update adds a CPU-only synthetic training and inference walkthrough, bilingual entry points and wheel/sdist checks. Historical model and research results retain their original scope. The artifacts do not ship pretrained weights or student essays. Use [Quick start](synthetic-quickstart.md) and the [model card](model-card.md).

本次更新补齐双语入口、CPU 合成样例与 Python 构建检查。历史模型分数和实验边界保持原样。发行内容不包含模型权重或学生作文。详见[入门](synthetic-quickstart.md)和[模型卡](model-card.md)。

PyPI publishing requires package-name and namespace verification, a clean artifact inspection, and maintainer approval. Source licensing does not extend to datasets or weights. / 公开分发前需核对包名与发布权限、检查产物内容，并由维护者确认。源码许可证不覆盖数据或权重。
